# fiskl

Connects Claude to your Fiskl accounting data, and adds the domain expertise to work
with it correctly.

This repo is the published build of the `fiskl` production plugin. Source of truth,
build tooling, and the staging (sandbox) variant live in Fiskl's internal repo; this repo
holds only the plugin contents Anthropic's marketplace pulls in for review and serving.

See [help.fiskl.com](https://help.fiskl.com/integrations/public-api/connect-ai-assistant)
for setup and usage.
